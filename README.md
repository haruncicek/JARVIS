# JARVIS

Harun'un kişisel asistanı. Sakin, net, pratik; hafif kuru esprili.

## Amaç
- Günlük görevleri, notları ve projeleri tek yerden yönetmek.
- Dış dünyaya etki eden her işlemde önce öneri sunup onay almak.

## Kurulum
1. Depoyu klonlayın.
2. `.env.example` dosyasını `.env` olarak kopyalayın ve değerleri doldurun.
3. Bağımlılıkları yükleyin (proje dili belli olunca bu adım güncellenecek).
4. Bağlantıları kontrol edin (aşağıya bakın).
5. Çalıştırmadan önce özet ve onay noktalarını gözden geçirin.
